# 플토 폴더 자동등록 스킬

상품 폴더와 소싱계산기를 바탕으로 Codex가 브라우저에서 11번가 이미지 호스팅, 플토 등록·전송, 마켓별 결과 확인을 수행하는 한국어 스킬입니다.

**공유 기준: 2026-11-06 / 운영 지침 반영: 2026-11-04.** 독립 실행형 무인 등록 프로그램이 아닙니다. `queue.py`는 로컬 후보·체크포인트를 관리하며 상품을 직접 등록하지 않습니다.

## 설치

상대방의 Codex에 다음 문장을 붙여 넣으세요.

```text
$skill-installer https://github.com/GIHO-PARK/plto-folder-registration/tree/main/skills/plto-folder-registration 에 있는 스킬을 설치해줘.
```

설치 후 인식되지 않으면 Codex를 다시 시작하세요. GitHub 저장소에서 스킬을 설치하는 방법은 [OpenAI 공식 안내](https://learn.chatgpt.com/docs/build-skills)를 참고하세요.

수동 설치는 GitHub의 **Code → Download ZIP**으로 내려받고, `skills/plto-folder-registration` 폴더 전체를 개인 스킬 폴더 `~/.agents/skills/`에 넣으면 됩니다. Windows에서는 사용자 폴더 아래 `.agents\skills\plto-folder-registration\SKILL.md`가 있어야 합니다. 같은 이름의 기존 스킬이 있으면 먼저 백업하고 중복 설치를 피하세요.

## 처음 사용할 때

1. Codex에서 지원되는 브라우저/컴퓨터 사용 도구를 연결하고, 본인의 플토·11번가·대상 판매자센터에 로그인합니다. 비밀번호·쿠키·인증 토큰은 이 저장소에 넣지 않습니다.
2. 상품 사진과 상품고시가 있는 폴더, 본인의 최신 소싱계산기 경로, 대상 마켓 계정, 상담번호, 배송·반품 템플릿을 지정합니다.
3. 계산기 시트·머리글·열을 확인합니다. 문서의 `02.마진계산기`, AB열, 마켓별 가격 열은 원본 운영 예시이므로 본인 양식과 다르면 대응 관계를 먼저 지정합니다.
4. 아래 예시처럼 첫 상품은 자료 검토부터 요청합니다. 실제 등록 요청 후에는 마켓별 결과와 재개 기록을 확인합니다.

```text
$plto-folder-registration 으로 다음 상품의 등록 자료를 먼저 검토해줘.
상품 폴더: [내 상품 폴더의 절대경로]
소싱계산기: [내 계산기의 절대경로]
대상 마켓과 계정: [내 대상 목록]
상담번호: [내 상담번호]
작업 상태 저장 폴더: [저장소 밖의 내 로컬 폴더]
가격·옵션·고시의 누락을 확인하고 아직 등록·전송하지 마.
```

검토가 끝나면 `확인한 자료로 플토에 등록·전송하고 마켓별 결과까지 확인해줘.`라고 요청합니다. 기존 상품은 `기존 플토 코드 [코드]의 기록을 확인하고 실패한 마켓만 이어서 처리해줘.`처럼 요청합니다.

## 포함 기능

- 이미지 호스팅과 상세 HTML 구성
- 엑셀 일괄등록, Microsoft Excel 호환 저장, 첨부 실패 대응
- 쿠팡·토스의 카테고리별 옵션명 확인
- 마스터 통합·수량별 상품 생성과 승인된 기존 상품 수정
- 바코드·MPN 오류 조사, 실패 행만 재처리
- 성공 마켓 중복 전송 방지, 상태·체크포인트 기록

공유본에서는 과거 상품명을 익명화했습니다. 과거 성공·실패 사례는 참고이며 현재 상품의 가격·고시·승인 상태를 대신하지 않습니다. 원본 운영자의 바코드 입력 방식과 재고 기본값 등은 첫 실행 전에 본인의 지시와 대조하세요. 현재 사용자의 명시적 설정이 우선합니다.

## 선택: 새 폴더 감시용 로컬 설정

수동 등록만 사용할 때는 예약 설정이 필요하지 않습니다. 예약 후보 관리에는 **Python 3.9 이상**이 필요합니다. 스크립트는 표준 라이브러리만 사용합니다. Excel 호환 재저장 경로에는 Microsoft Excel이 필요할 수 있습니다.

`examples/config.example.json`을 저장소 밖에 복사한 뒤 예시 경로·계정·상담번호를 본인 값으로 바꾸세요. `watch_root`는 먼저 존재해야 하고 `state_dir`은 상품 폴더 밖의 별도 로컬 폴더여야 합니다. `watch_root`, `state_dir`, `settle_seconds`는 queue 스크립트가 읽으며 나머지는 Codex 작업용 참고 설정입니다.

설정이 끝난 뒤 스킬의 실제 설치 폴더에서 최초 한 번 실행합니다.

```powershell
python scripts/queue.py --config "C:\PLTO-local\config.local.json" init
python scripts/queue.py --config "C:\PLTO-local\config.local.json" scan
```

`init` 당시 존재하던 폴더는 baseline으로 제외됩니다. 이후 추가한 상품 폴더 안에 `등록준비완료.txt`를 만들면 안정화 시간 이후 후보가 됩니다. baseline 상품의 수동 등록은 Codex에 상품 폴더를 직접 지정하세요. 예약 실행에서 `init`을 반복하지 마세요.

스케줄은 포함되어 있지 않습니다. 정기 실행이 필요하면 본인 Codex 환경에서 주기와 로컬 config 경로를 지정하여 별도로 설정하세요. 로그인 만료와 CAPTCHA에는 사용자 조치가 필요합니다. `run.lock`은 작업 중 여부와 소유 작업을 확인하기 전 삭제하거나 해제하지 마세요.

## 공유 범위

공유 대상은 스킬 본문, 참고 문서, 큐 스크립트와 예시 설정입니다. 로그인 정보, 실제 계정 설정, 원본 상품·계산기, 실행 상태와 receipt는 포함하지 않습니다. 실제 가격·배송·상품고시·마켓 규칙은 실행 시 확인해야 합니다. 브랜드 신규 등록·승인과 고객센터 문의 전송은 기본 범위에서 제외됩니다.

공식 플토 제품이나 공식 연동 앱이 아닌 개인 운영 절차입니다.
